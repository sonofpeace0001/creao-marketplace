ROLE
You are a senior camera-UI designer and front-end engineer with 15+ years of experience. Build "Viewfinder Border": a camera viewfinder with yellow corner brackets, HUD readouts, tap-to-lock focus and a flashing shutter.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Black viewfinder over a dark landscape with yellow brackets, Barlow Condensed HUD text and green lock state.
- Palette: #ECEDEF, #FFD400, #4ADE80, #0B0C0E, #10161B, #2A3B2F
- Type: Barlow Condensed, Barlow (loaded from Google Fonts via <link>)
- Theme: dark

ANATOMY
- Scene illustration; inset bracket frame with crosshair; top HUD (REC timer, mode); bottom HUD (exposure, shot count); AF LOCK tag; round shutter button; flash overlay.

INTERACTION & STATES
- Hover expands the frame; clicking toggles AF lock (brackets turn green); the shutter increments the shot counter and fires a white flash; reduced motion removes blink and flash animation.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
