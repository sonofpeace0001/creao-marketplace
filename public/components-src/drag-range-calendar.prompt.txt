ROLE
You are a senior travel-booking designer and front-end engineer with 15+ years of experience. Build "Drag Range Calendar": a two-month stay picker where you drag across days to select a range, with hover preview, presets and a night count.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Warm parchment card with Fraunces headings and a terracotta range band.
- Palette: #C2410C, #241D12, #FBF8F1, #8A7E66, #EFE8D8, #F2EDE4
- Type: Fraunces, Work Sans (loaded from Google Fonts via <link>)
- Theme: light

ANATOMY
- Header with night count and date range; two month grids with navigation; range band with rounded ends; preset chips (Weekend, One week, Two weeks, Clear); Check availability button.

INTERACTION & STATES
- Pointer down starts a range and dragging extends it; releasing finalises; hovering after a first click previews the band; keyboard Enter or Space picks start and end; presets set ranges.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
