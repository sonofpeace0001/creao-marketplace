Install the CLI

Set up the command-line tool in under a minute, then verify that everything works.

1

Install the package

Install it globally with your package manager. Node 18 or newer is required.

terminal
# npm
$ npm install -g @acme/cli
2

Sign in

Run acme login and approve the request in your browser. Your token is stored securely.

Using CI?

Set the ACME_TOKEN environment variable instead of running the interactive login.
