ROLE
You are a senior product designer and front-end engineer (developer-tool marketing) with 15+ years of experience. Build "Release Pill": a floating release announcement pill with a rotating conic-gradient border, version tag and dismiss.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Quietly premium: a midnight page with a faint grid and one glowing pill that feels like a shipping note.
- Palette: #0B1120, #35E0A1, #4C8DFF, #C9D3E6, #14243F, #070A12
- Type: Instrument Sans, Geist Mono (loaded from Google Fonts via <link>)
- Theme: dark

ANATOMY
- Pill with a gradient 'v3.4' tag, headline phrase, 'What's new' link with arrow, and a round dismiss button.
- Large page headline beneath with a one-line subhead; a ghost button to bring the pill back.

INTERACTION & STATES
- Border is a conic-gradient animated via @property --a (5s loop).
- Dismiss fades and lifts the pill; the restore button reverses it.
- Arrow slides 3px on link hover.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
