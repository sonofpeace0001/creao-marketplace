ROLE
You are a senior collaboration product designer and front-end engineer with 15+ years of experience. Build "Combobox Suggest Input": a multi-select people picker with avatar suggestions, matched text highlighting, full keyboard navigation and removable chips.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Cool grey canvas, white surfaces and an indigo accent with colour-coded avatars.
- Palette: #4F46E5, #101524, #5A6280, #D8DDEB, #EEF0FF, #8A91AE
- Type: Inter Tight (loaded from Google Fonts via <link>)
- Theme: light

ANATOMY
- Label; chip field with input; popover list of up to four matches with avatar, name, role and a check for selected people; key hint footer.

INTERACTION & STATES
- Typing filters and bolds the match; arrows move the highlight, Enter toggles selection, Backspace removes the last chip, Escape closes; click selects without losing focus.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

MOTION SPEC (exact values, do not approximate)
- List enters 220ms from translateY -6px and scale .985; chips pop with a 350ms spring.

IDLE AUTOPLAY
- The list opens, a query is typed, the highlight moves, a person is added, a second search runs, then it closes and resets.
- Autoplay stops permanently on the first real pointer, touch or key event and is fully disabled under prefers-reduced-motion.

AVOID (these make it generic)
- Losing the input focus on option click; use mousedown.
- Unbounded lists; cap the visible matches.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
