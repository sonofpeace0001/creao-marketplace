ROLE
You are a senior e-commerce designer and front-end engineer with 15+ years of experience. Build "Shipping Panels": neo-brutalist FAQ panels with icon tiles, plus/minus toggles and a hard shadow that shifts when open.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Cream background, thick ink borders, hard offset shadows that turn orange when a panel is open.
- Palette: #241F18, #7A6F5E, #D9531E, #F2EEE6, #5C5242, #F7F3EA
- Type: Libre Franklin (loaded from Google Fonts via <link>)
- Theme: light

ANATOMY
- Heading and subline; three panels (Delivery options, Returns & exchanges, International shipping) with coloured icon tiles, title/sub, plus-minus control, and answer content (a small options list in the first).

INTERACTION & STATES
- Panels toggle independently with a height animation; the plus morphs to minus and the shadow shifts up-left.
- Buttons expose aria-expanded and have a strong focus ring.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
