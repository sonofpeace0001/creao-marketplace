ROLE
You are a senior pricing designer and front-end engineer with 15+ years of experience. Build "Billing Period Toggle": a monthly or yearly switch with a sliding highlight and a hand-drawn Save 20% arrow, driving three plan cards whose price digits roll to the new amount.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Ink navy with indigo and violet accents, handwritten green annotation and tabular rolling digits.
- Palette: #8B93A8, #4ADE80, #141821, #A5ADC4, #0E1117, #EEF1F8
- Type: Sora, Caveat (loaded from Google Fonts via <link>)
- Theme: dark

ANATOMY
- Heading; pill switch with highlight and annotation; three plan cards (Starter, Pro popular, Scale) with rolling price, billing line and feature list.

INTERACTION & STATES
- Choosing Yearly applies a 20 percent discount, rolls every digit, and rewrites each billing line with the annual total and the amount saved.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

MOTION SPEC (exact values, do not approximate)
- Highlight slides and resizes 500ms cubic-bezier(.3,1.3,.4,1); each digit is a 0 to 9 reel translating 700ms cubic-bezier(.3,1.2,.4,1); the arrow redraws via stroke-dashoffset in 600ms.

IDLE AUTOPLAY
- The period flips every 2.8s.
- Autoplay stops permanently on the first real pointer, touch or key event and is fully disabled under prefers-reduced-motion.

AVOID (these make it generic)
- Swapping prices without animation.
- Showing a discount without the real annual total.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
