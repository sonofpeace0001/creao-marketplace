ROLE
You are a senior interaction designer and front-end engineer (desktop-style web apps) with 15+ years of experience. Build "Glass Dock": a frosted-glass desktop dock with cursor-proximity magnification, tooltips and bounce-on-launch.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Warm desktop wallpaper in peach, periwinkle and pink with a translucent dock of glossy gradient app tiles.
- Palette: #FFD2A8, #B9C8FF, #F8A6C8, #F3E4DC, #241B2B, #3B2F46
- Type: Onest (loaded from Google Fonts via <link>)
- Theme: light

ANATOMY
- Menu bar strip, wallpaper, and a centred dock with five app tiles, a separator and a trash tile.
- Each tile has a gradient, custom inline icon, running-indicator dot and a tooltip.

INTERACTION & STATES
- Tiles scale up to 1.75× based on distance from the cursor (pointermove) and ease back on leave; neighbours spread apart.
- Clicking a tile bounces it and marks it running.
- Magnification is disabled under prefers-reduced-motion.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
