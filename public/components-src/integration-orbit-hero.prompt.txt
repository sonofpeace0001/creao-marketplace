ROLE
You are a senior product marketing designer and front-end engineer with 15+ years of experience. Build "Integration Orbit Hero": a product hero with a glowing core surrounded by three concentric rings of integration icons that orbit at different speeds while staying upright.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Midnight navy with electric blue and cyan, dashed orbit rings and colour-coded line icons on dark glass tiles.
- Palette: #22D3EE, #E6ECFB, #3B82F6, #070D1C, #8FA0C6, #60A5FA
- Type: Plus Jakarta Sans (loaded from Google Fonts via <link>)
- Theme: dark

ANATOMY
- Nav; eyebrow, headline with gradient phrase, supporting copy, two buttons, three proof stats; orbit with pulsing core and 12 nodes across 3 rings.

INTERACTION & STATES
- No input required; hover states on buttons only.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

MOTION SPEC (exact values, do not approximate)
- Rings rotate 26s, 42s (reverse) and 62s linear; each node counter-rotates by the same angle so icons stay upright.
- Core emits a 2.6s expanding ring pulse and carries two concentric halos.

IDLE AUTOPLAY
- The orbit runs continuously from the first frame.
- Autoplay stops permanently on the first real pointer, touch or key event and is fully disabled under prefers-reduced-motion.

AVOID (these make it generic)
- Icons that spin with their ring and end up upside down.
- Brand logos you do not have rights to; icons are generic line glyphs.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
