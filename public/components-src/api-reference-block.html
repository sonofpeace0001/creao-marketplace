POST/v1/customers

Create a customer

Creates a new customer object. You can attach metadata and a default payment method in the same request.

Body parameters

emailstringrequired

The customer's email address, used for receipts.

namestring

Full name or business name.

metadataobject

Up to 20 key-value pairs for your own use.

payment_methodstring

ID of a payment method to attach and set as default.
