Authentication

Learn how to authenticate your requests, rotate keys safely and scope access for every environment.

API keys

Every request must include a secret key in the Authorization header. Keys are created in the dashboard and shown only once.

Authorization: Bearer sk_live_51Hx...
NoteTest keys start with sk_test and never move real money.

Scopes

Restrict a key to the exact resources it needs. A read-only key can list customers but cannot create or delete them.

Scopes are checked on every call and return 403 when the key lacks permission.

Rotating keys

Create a new key, deploy it, then revoke the old one. Both keys work during the overlap so you never drop a request.

WarningNever commit secret keys to source control or ship them in client code.

Environments

Use separate keys for development, staging and production, and store them in your platform secret manager.

Webhook signing secrets are independent from API keys and can be rotated on their own.

Troubleshooting

A 401 means the key is missing or revoked. Check for stray whitespace and confirm the environment prefix.
