ROLE
You are a senior motion designer and creative developer with 15+ years of experience. Build "Liquid Text Hero": a motion-studio hero with one giant word filled by drifting colour blobs and rippled by an animated turbulence displacement filter.

GOAL
One self-contained HTML file that looks like part of a funded product's real interface — specific, considered and never a generic template.

ART DIRECTION
- Mood: Ink-black with violet and cyan ambient light; a single oversized wordmark in a blown-out geometric face filled with pink, sky and amber gradients.
- Palette: #0A0B12, #EEF0FA, #7C3AED, #9CA2C4, #A5B4FC, #F472B6
- Type: Syne, Figtree (loaded from Google Fonts via <link>)
- Theme: dark

ANATOMY
- Nav; eyebrow; giant gradient word; copy; reel button; bottom ticker of services.

INTERACTION & STATES
- Hover and focus states on buttons only; the headline is the show.
- Every interactive element has a visible :focus-visible state and a sensible hover/active state.

MOTION SPEC (exact values, do not approximate)
- Fill: three radial gradients whose centres animate via registered @property percentages over 9s ease-in-out alternate, clipped to the text.
- Ripple: feTurbulence baseFrequency animated over 14s through an feDisplacementMap with scale 15.
- Ticker translates -50% over 26s linear.

IDLE AUTOPLAY
- Everything moves on its own: fill, ripple and ticker.
- Autoplay stops permanently on the first real pointer, touch or key event and is fully disabled under prefers-reduced-motion.

AVOID (these make it generic)
- Displacement so strong the word becomes unreadable; scale stays at 15.
- Gradient text with no motion, which looks like a template.

CONSTRAINTS
- Single HTML file with inline CSS (and only the small amount of vanilla JS the behaviour needs). No frameworks, no build step.
- Inline SVG icons only — no emoji, no stock imagery. Real, specific copy; no lorem ipsum.
- Responsive from 360px up; honour prefers-reduced-motion; keep text contrast at WCAG AA or better.
- Semantic HTML with proper roles/labels where the component is interactive.

ACCEPTANCE CHECKLIST
- No layout shift, overflow or clipped text at 1440px and 390px.
- Every state described above is reachable and looks intentional.
- It could not be mistaken for a different component or another product's default styling.
